# References

This project follows the architecture presented in Ben Eater's 8-bit breadboard computer series.

## Official Ben Eater material

- Project overview: https://eater.net/8bit
- Schematic index: https://eater.net/8bit/schematics
- High-level architecture: https://eater.net/schematics/high-level.png
- ALU schematic: https://eater.net/schematics/alu.png
- Complete KiCad project: https://eater.net/downloads/8bit-computer.zip
- EEPROM programmer source: https://github.com/beneater/eeprom-programmer
- Video series: https://www.youtube.com/playlist?list=PLowKtXNTBypGqImE405J2565dvjafglHU

## Repository policy

External reference designs are linked here rather than copied into the project-specific hardware folders.

The Arduino EEPROM programming files that are included directly in this repository are identified in `THIRD_PARTY_NOTICES.md`.
